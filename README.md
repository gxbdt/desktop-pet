# 桌面金毛

一只住在 Windows 桌面上的幼年金毛。它是一个透明置顶窗口，会自己走动、跟着鼠标、追着被拖动的文件，也能按右键菜单去做事。

## 环境

- Windows 10 或更高版本
- Python 3.12
- 依赖：`pywin32`、`Pillow`、`numpy`

## 启动

安装依赖：

```bat
python -m pip install -r requirements.txt
```

双击 `启动桌面宠物.bat`，或在项目目录运行：

```bat
pythonw main.py
```

同一时间只能有一只。再次启动时会提示「小狗已经在桌面上啦」。

## 怎么互动

- **左键点一下**：摸摸它。
- **按住拖动**：把它拎到别的地方。
- **右键**：打开菜单。
- **把文件拖过桌面**：它会跑过去闻。文件拖到它身上时，它会叼住再放好。

## 右键菜单

| 菜单 | 它会做什么 |
| --- | --- |
| 摸摸头 / 喂零食 | 开心一下，亲密度会增加 |
| 自己玩 / 跟着我 / 安静待着 | 自己溜达、跟着鼠标，或待在原地 |
| 去睡觉 / 起来玩 | 睡着，或起来玩一会儿 |
| 去标记一下 | 走到附近的桌面图标旁，抬腿做标记 |
| 去拉臭臭 | 找到桌面上的回收站，跑过去对着它尿尿 |
| 查找文件… | 输入名字，只在桌面文件夹里找。找到后跑到那个图标旁汪汪叫 |
| 大小 | 小只、正常、大只 |
| 给它起名字… | 名字最多 8 个字，默认叫「小金」 |
| 开机自动出现 | 写入当前用户的开机启动项 |
| 退出 | 关掉小狗，并记住当前设置 |

查找只认桌面文件夹里直接放着的文件和文件夹，例如 `C:\Users\你的用户名\Desktop`。子文件夹里面的文件没有自己的图标，所以不在查找范围内。回收站如果被隐藏，拉臭臭时它会说「没看到回收站」。

## 会记住的内容

设置写在项目目录的 `settings.json` 里，包括名字、行为模式、大小和亲密度。出错时可以看同目录的 `pet.log`。

## 项目结构

```
main.py                 启动入口，保证只有一只
启动桌面宠物.bat         用 pythonw 后台启动
pet/app.py              透明窗口、鼠标和右键菜单
pet/dog.py              位置、心情和要做的事
pet/desktop.py          读取桌面图标，查找桌面上的文件和回收站
pet/sprite.py           把小狗画出来
pet/motion.py           腿和尾巴的动作
figma-assets/           各个姿势的贴纸
```
